switch...case 介紹

多重條件選擇的優雅解法

為什麼需要 switch...case？

💡 回顧：之前的單元學過 if...else if...else 處理「範圍判斷」（例如：溫度 > 30 度）。

⚠️ 痛點：遇到「固定選項/特定數值」時（例如：按 1 開冷氣、按 2 開暖氣），寫一連串 else if 容易讓程式碼顯得冗長且混亂，且容易混淆 if 與 else 的配對。

✨ 解法：使用 switch...case 結構，可以精準比對特定選項，提升程式碼的可讀性與執行效率！

switch...case 語法結構與格式說明


switch (控制表達式) {
    case 等值條件1:
        // 當控制表達式等於「條件1」時執行
        break;
    case 等值條件2:
        // 當控制表達式等於「條件2」時執行
        break;
    default:
        // 以上皆不匹配時的預設程式碼
        break;
}
  • switch (控制表達式)：放入要比對的變數或算式（須為明確固定值，如整數 int 或字元 char）。
  • case 等值條件: 比對目標，後接固定值與冒號 :。相符時跳至該處執行。
  • break; (非常重要)：跳出 switch 區塊。若漏寫會發生貫穿效應 (Fall-through)。
  • default: (選擇性)：類似 else，當完全未命中任何 case 時執行。

🧠 思考與互動問答

情境題：打電話到學校時，語音系統提示：
「想轉接學務處請按 1，教務處請按 2，總務處請按 3，結束請按任意鍵。」

👉 請思考：如果用 switch(input_key) 寫，流程圖該怎麼畫？

💡 思考關鍵：

  • case 1 ➔ 轉接學務處 ➔ break;
  • case 2 ➔ 轉接教務處 ➔ break;
  • case 3 ➔ 轉接總務處 ➔ break;
  • default ➔ 按任意鍵 ➔ 結束語音系統。

總結

  • 固定值、多選項判斷 ➔ 優先使用 switch...case。
  • 範圍大小判斷 ➔ 使用 if...else if...else。
  • 別忘了在每個 case 結束時加上 break;！
