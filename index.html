  • 客服語音總機（按 1 轉專人、按 2 查帳單...）
  • 遊戲按鍵控制（W:上、S:下、A:左、D:右）
  • 星期選單（1~7 對應 星期一~星期日）

switch...case 語法結構

switch (控制表達式) {
    case 等值條件1:
        // 執行程式碼 1
        break;
    case 等值條件2:
        // 執行程式碼 2
        break;
    default:
        // 當無匹配時執行的預設程式碼
        break;
}

重點關鍵字解析

  • switch (控制表達式)：放入要比對的變數（如整數 int 或字元 char），不可放 x > 10 這種範圍判斷。
  • case 等值條件 : 比對目標，後接固定值與冒號。
  • break;（極度重要）：跳出 switch 區塊。若漏寫會發生貫穿效應（Fall-through）！
  • default: 相當於 else，處理未命中或輸入錯誤的情況。
