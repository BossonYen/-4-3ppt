switch...case 介紹

多重條件選擇的優雅解法

為什麼需要 switch...case？

💡 回顧：之前的單元學過 if...else if...else 處理「範圍判斷」（例如：溫度 > 30 度）。

⚠️ 痛點：遇到「固定選項/特定數值」時（例如：按 1 開冷氣、按 2 開暖氣），寫一連串 else if 容易讓程式碼顯得冗長且混亂，且容易混淆 if 與 else 的配對。

✨ 解法：使用 switch...case 結構，可以精準比對特定選項，提升程式碼的可讀性與執行效率！

switch...case 語法結構與格式說明


switch (控制表達式) {
    case 等值條件1:
        // 條件1成立時執行的程式碼
        break;
    case 等值條件2:
        // 條件2成立時執行的程式碼
        break;
    default:
        // 以上皆不匹配時的預設程式碼
        break;
}
  • switch (控制表達式)：放入要比對的變數或算式（須為明確固定值，如整數 int 或字元 char，不可放範圍條件）。
  • case 等值條件: 比對目標，後接固定值與冒號 :。相符時即跳至該處執行。
  • break; (非常重要)：跳出 switch 區塊。若漏寫會發生貫穿效應 (Fall-through)，繼續執行下一個 case。
  • default: (選擇性)：類似 else，當完全未命中任何 case 時執行（常用於錯誤處理）。

🧠 思考與互動問答

Q：除了電梯和販賣機，生活中有哪些狀況也很適合用 switch...case 處理？

💡 學生可能提出的參考答案：

  • 客服電話語音選單：「國語服務請按 1，English Service press 2，專人服務請按 0，輸入錯誤請重新輸入 (default)」。
  • 遊戲選單 / 鍵盤操控：按下 'W' 上移、'S' 下移、'A' 左移、'D' 右移。
  • 紅綠燈號誌控制：「紅燈」停、「綠燈」行、「黃燈」減速。
  • 成績等第轉換：等級 'A' 顯示優秀、'B' 顯示良好、'F' 顯示不及格。

總結

  • 固定值、多選項判斷 ➔ 優先使用 switch...case。
  • 範圍大小判斷 ➔ 使用 if...else if...else。
  • 別忘了在每個 case 結束時加上 break;！
