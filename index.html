switch...case 介紹

多重條件選擇的優雅解法

為什麼需要 switch...case？

💡 回顧：之前的單元學過 if...else if...else 處理「範圍判斷」（例如：溫度 > 30 度）。

⚠️ 痛點：遇到「固定選項/特定數值」時（例如：按 1 開冷氣、按 2 開暖氣），寫一連串 else if 容易讓程式碼顯得冗長且混亂[cite: 4]，且容易混淆 if 與 else 的配對。

✨ 解法：使用 switch...case 結構，可以精準比對特定選項，提升程式碼的可讀性與執行效率！

switch...case 語法結構說明


switch (控制表達式) {
    case 等值條件1:
        // 當等於「條件1」時執行
        break;
    case 等值條件2:
        // 當等於「條件2」時執行
        break;
    default:
        // 以上皆不匹配時的預設程式碼
        break;
}
  • switch (控制表達式)：放入要比對的變數或算式（須為明確固定值，如整數 int 或字元 char）[cite: 4]。
  • case 等值條件: 比對目標，後接固定值與冒號 :。相符時跳至該處執行[cite: 4]。
  • break; (非常重要)：跳出 switch 區塊[cite: 4]。若漏寫會發生貫穿效應 (Fall-through)[cite: 4]。
  • default: (選擇性)：類似 else，當完全未命中任何 case 時執行[cite: 4]。

    }
    return 0;
}

🪐 文章閱讀：宇宙級問號 Kepler-22b

【驚天謎團】系外行星 Kepler-22b 的人為設計痕跡

開普勒22B (Kepler-22b) 是一顆體積為地球 2.4 倍的系外行星[cite: 4]。令人震撼的是，它剛好落在理論上不應存在行星的「富爾頓禁區 (1.5 ~ 2.0 倍地球半徑)」邊緣[cite: 4]。若人類身處該環境，心臟需承受三倍負荷，骨骼系統數月內便會崩潰[cite: 4]。

更令人驚奇的是其軌道參數：軌道偏心率僅為 0.001，在數學意義上幾乎是極度完美的正圓[cite: 4]。恆星周圍乾淨無比，沒有任何殘留的小行星或星際碎片[cite: 4]。公轉週期為 290 天，表面平均溫度約 22 度[cite: 4]。

2015 年，天文團隊更記錄到「週期性有規律的電磁波，頻率間隔呈現 1, 2, 4, 8... 數學級數特徵」[cite: 4]。若其存在生命，進化速度預計比地球快 20%~25%[cite: 4]，科技可能領先人類約 762 年[cite: 4]。科學家提出兩大假說：這可能是一顆被高級文明改造過的行星，或者根本就是一個宇宙級別的人造實驗場[cite: 4]！

📝 練習 1：語法陷阱與常數宣告

完整程式碼片段：


#include <iostream>
using namespace std;

int main() {
    const double MIN_RADIUS = 1.5;
    const double MAX_RADIUS = 2.0;
    double planetRadius = 2.4; // 開普勒22B為地球的2.4倍

    // 選項比對位置
    return 0;
}

Ⓐ 使用 const double 宣告界限是正確的做法[cite: 4]。

Ⓑ 判斷是否在禁區內寫成：if (1.5 <= planetRadius <= 2.0) 是正確的 C++ 語法[cite: 4]。

Ⓒ 判斷是否在禁區內應寫成：if (planetRadius >= MIN_RADIUS && planetRadius <= MAX_RADIUS)[cite: 4]。

Ⓓ 若要儲存「是否為禁區天體」的結果，適合使用 bool 型別[cite: 4]。

❌ 錯誤選項為：(B)

解析：C++ 不能寫 1.5 <= x <= 2.0！這會先計算 (1.5 <= x) 得到 1 或 0，再拿去與 2.0 比較導致邏輯錯誤[cite: 4]。正確寫法須像選項 (C) 使用 && 連接[cite: 4]。

📝 練習 2：軌道檢測完整程式碼


#include <iostream>
using namespace std;

int main() {
    double eccentricity;
    int asteroidCount;

    // 輸入測試資料：0.001 0
    cin >> eccentricity >> asteroidCount;

    // 區塊一：軌道異常檢測
    if (eccentricity < 0.005 && asteroidCount == 0) {
        cout << "System: Artificial Trait Detected\n";
    } else if (eccentricity < 0.017) {
        cout << "System: Natural Stable Orbit\n";
    } else {
        cout << "System: High Perturbation\n";
    }

    // 區塊二：縮排陷阱與條件式
    int lightYears = 635;
    if (lightYears < 500)
        cout << "Target: Close Range\n";
        cout << "Scan Complete\n";

    return 0;
}

📝 練習 3：小明的 Debug 時間

小明撰寫了以下評估文明領先年數的程式片段，請找出兩處嚴重錯誤[cite: 4]：


#include <iostream>
using namespace std;

int main() {
    int distance = 635;
    double speedup = 0.20; // 假設進化速度快 20%

    int leadYears = distance + distance * speedup;
    if (0.20 <= speedup <= 0.25) {
        cout << "進入高危險文明評估區間" << endl;
    }
    return 0;
}

總結

  • 固定值、多選項判斷 ➔ 優先使用 switch...case[cite: 4]。
  • 範圍大小判斷 ➔ 使用 if...else if...else[cite: 4]。
  • 別忘了在每個 case 結束時加上 break;[cite: 4]！
  • 注意 C++ 邏輯運算子，切勿寫出連比語法如 a <= b <= c[cite: 4]！

🔍 小明程式碼的錯誤解答報告

錯誤第 1 處：
if (0.20 <= speedup <= 0.25)
原因：C++ 不支援數學上的連續比較語法[cite: 4]。應改寫為：
if (speedup >= 0.20 && speedup <= 0.25)[cite: 4]

錯誤第 2 處：
int leadYears = distance + distance * speedup;
原因：右側計算包含小數 (0.20)，但接收變數 leadYears 宣告為整數 int，會導致小數點被無條件捨去[cite: 4]。應宣告為 double[cite: 4]。
